FAQ

Intelligent search in MongoDB combines full-text, vector, and hybrid retrieval capabilities so teams can deliver more relevant search experiences and stronger AI context without stitching together separate systems.

Hybrid search combines lexical search from MongoDB Search with semantic retrieval from MongoDB Vector Search so teams can improve precision and relevance in a single MongoDB-based architecture.

Full-text search helps match keywords, phrases, and synonym-based intent in structured and unstructured content. Vector search helps retrieve results based on semantic similarity. Together, they can support richer retrieval experiences than either approach alone.

Learn more about MongoDB Search and MongoDB Vector Search.

Use hybrid search when you want both lexical precision and semantic understanding in the same retrieval workflow, such as product discovery, knowledge search, conversational experiences, and AI applications that need strong context retrieval.
