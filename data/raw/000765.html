MongoDB Search

MongoDB Search is the simplest way to build relevance-based search 4x faster and move beyond the performance limits of basic search operators.

Advanced search, simplified

With MongoDB Search, you work with a single, unified API across both your database and search operations, simplifying your queries and reducing development time by eliminating the need for unscalable manual query logic or basic text operators.

Deliver search features faster

Enterprise-grade search

Atlas automates provisioning, patching, scaling, and disaster recovery while providing robust security. Gain deep visibility into search operations to identify and resolve performance friction before it impacts your production environment or CPU usage.

Superior performance at scale

Optimize compute resources to scale search and database needs independently for better performance with up to 60% reduction in query times—even for complex query types. Overcome the single-index limits of basic operators to ensure search remains fast as your dataset and complexity grow.

Learn about Atlas Search Nodes

Build search directly in Atlas

Manage search for your evolving application needs without the hassle of standing up and managing a sync mechanism, writing custom transformation logic, or remapping search indexes.

Instantly improve retrieval accuracy using Voyage AI's best-in-class reranker models without leaving the MongoDB query engine. With MongoDB native reranking, only the most relevant results reach your LLM, reducing token costs and latency for agentic and multi-step retrieval pipelines.

FAQ

MongoDB Search is an embedded full-text search capability built on Apache Lucene. It provides a scalable, relevance-based experience that eliminates the need for bolt-on search solutions. It also alleviates the performance and indexing limitations of basic search operators, such as $text or $regex.

Read more in our docs

MongoDB Search allows for keyword or lexical search (i.e., based on the actual text and any defined synonym mappings), whereas MongoDB Vector Search on Atlas allows searching through data based on semantic meaning captured in vectors.
